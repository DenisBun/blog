This is the first example post on my new website. It is built with Astro, but it borrows its visual language from the desktop computers of the 1990s.

## Why this look?

Old interfaces were direct. Windows looked like windows, buttons looked clickable, and every screen had a strong sense of place. I wanted to keep some of that character without giving up modern accessibility, responsive layouts, or fast pages.

## What comes next?

This post is intentionally simple. Replace it with a real article whenever you are ready, or keep it nearby as a reference for frontmatter, headings, categories, and tags.

```ts
const website = {
  framework: 'Astro',
  mood: 'Windows 95',
  languages: ['en', 'ru'],
};
```

The useful parts are already wired up: RSS, social previews, structured data, pagination, translated routes, and an automatically generated table of contents.
